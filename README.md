# 無界塾 MIS 問卷自動填寫

這是一個適用於 [Tampermonkey](https://www.tampermonkey.net/) 使用者脚本，可自動將無界塾 MIS 問卷全部勾選「非常同意」。

## 直接安裝到Tampermonkey

>：點擊下方連結，會自動呼叫 Tampermonkey 安裝視窗。
此腳本需要搭配Tampermonkey使用Tampermonkey](https://www.tampermonkey.net/)。

### [ 🥵點此安裝脚本](https://raw.githubusercontent.com/stevewukc0789-png/-mis-/main/mis-auto-fill.user.js)

若點擊後沒有出現安裝視窗，請確認已安裝 [Tampermonkey](https://www.tampermonkey.net/)。

## 使用說明
https://drive.google.com/file/d/1XZayafrvjOphBA-bqbaZV9W2bk0u0Cz6/view?usp=sharing
1. 先點開一份問卷，確認題目已顯示
2. 點擊右下角的蓋色按鈕開始
3. 執行中按鈕會變紅並顯示進度，可點擊停止
4. 完成後請務必確認最後一題，並手動填寫下方質性回饋與學生自評

- 若出現逾時，請重新裝載頁面再試一次
